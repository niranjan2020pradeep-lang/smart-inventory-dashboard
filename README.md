# ProInventory

A lightweight web-based inventory and sales management system built using Flask and SQLite. Designed for small businesses to track stock levels, calculate net profits, and monitor sales analytics in real time.

## Features

- **Inventory Tracking:** Real-time stock updates with low-stock alert indicators.
- **Profit Analytics:** Automatically computes profit margins per sale and total cumulative profit.
- **Sales Logging:** Records sales history with relational database links to products.
- **Responsive Dashboard:** Dark-mode UI optimized for both desktop and mobile screens.

## Tech Stack

- **Backend:** Python (Flask)
- **Database:** SQLite3
- **Frontend:** HTML5, Modern CSS (Glassmorphic UI)
